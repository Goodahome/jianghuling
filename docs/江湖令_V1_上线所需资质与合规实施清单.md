## 一、项目统一定位（与现状一致）

江湖令是互联网平台型产品（非论坛、非传统中介、非普通跑腿）：

- 用户（令主）发布租房相关悬赏任务 → 其他用户（侠士）揭榜 → 协作完成 → 成果审核/验收 → 赏银分配 → 侠义值与声望成长
- MVP 聚焦：遵义单城试点 · 租房/出租/转租悬赏 · Web 响应式
- 准入：邀请制注册（无公开自助注册）
- 端形态：仅 Web；小程序/App 不在当前范围

后续除非业务模式发生重大变化（金融、直播带货、自营电商、招聘/网约等），均以「悬赏协作平台」为统一方向。

## 二、当前阶段划分（V1.0 未区分，现予补齐）

| 阶段 | 含义 |
|------|------|
| **A · 邀请制内测/试点（当前）** | 模拟银两钱庄；用户充值/提现入口隐藏；可用已部署域名做封闭内测；**不宣称「已合规完备」** |
| **B · 正式对外上线** | 完成主体与备案、规则齐全、内容审核与举报申诉闭环、合规支付评估/接入后再开放公网 |

下列「必须」项以阶段 B 为准；阶段 A 已具备项单独标注「内测已覆盖」。

### 4.2 重点评估（正式对外前）

1. **ICP 经营许可证**：用户发布信息、任务撮合 → 按经营性互联网信息服务评估  
2. **EDI 许可证**：若未来形成完整在线交易订单并由平台处理交易资金流再评估；**内测模拟结算 ≠ 已具备 EDI**  

### 4.3 内测已覆盖（不等于资质完成）

- 域名与 HTTPS（示例 `jianghu.kssrol.com`，以实际为准）  
- 用户协议/隐私政策页与注册勾选同意  
- 发令/成果双审核、武林盟后台运营能力  

## 五、统一资金方案（重要校正）

V1.0 原文「不建议自建钱包、不要用户充值→平台余额→提现」与**当前已实现的模拟钱庄**不符，现校正：

### 5.1 当前实现（阶段 A）

- 已实现模拟钱庄：余额/冻结/流水、悬赏托管与结算、注册赠银、邀新奖励、管理员调账  
- 用户侧充值/提现入口默认隐藏；不接微信/支付宝等真实通道  
- 须持续明示：银两为模拟记账，非法定货币，不可兑付人民币  

### 5.2 正式上线（阶段 B）

- 未完成合规评估前，不得对公网开放真实充值提现，或宣称可兑人民币  
- 不建议长期以「用户充值→平台自管余额→平台提现」作为对外主路径  
- 推荐：发令由合规第三方支付确认 → 完成/验收 → 结算；平台主责状态与结算记录  
- 从模拟钱庄切换真实支付时，须单独方案、协议修订与验收

## 七、实名认证与风控（与实现对齐）

- 注册：手机号 + 验证码或账号密码（内测可为 Mock，生产须真实短信）

- 正式上线建议分级：发令/高额→基础认证；高风险→增强；若开放提现→实名与支付账户一致性
